##  Инструкция для студентов 

### Шаг 1: Открытие ноутбука
1.  Перейдите по ссылке с бейджем **Open in Colab** из репозитория курса.
2.  Откроется копия ноутбука в вашем браузере. Она **не связана** с оригиналом — любые изменения видны только вам.

### Шаг 2: Выполнение задания
1.  Запустите каждую ячейку с  кодом по очереди (`Shift+Enter`)
2.  Найдите ячейки с задачами (обычно помечены `# TODO` или `# YOUR CODE HERE`).
3.  Напишите свой код и запустите ячейку с вашим кодом (`Shift+Enter`) и следующую ячейку с тестами, чтобы убедиться, что решение работает.
4. Продолжите дальше  с другими ячейками, дойдя до конца


### Шаг 3: Сохранение работы
> ⚠️ **Внимание:** Если вы просто закроете вкладку, ваша работа **пропадёт**. Коллаборативная сессия временная.

**Способ А (Рекомендуемый): Сохранение на диск**
1.  В меню выберите **File** → **Download** → **Download .ipynb**.
2.  Файл `pe_classification_decision_tree_task.ipynb` скачается на ваш компьютер.
3.  Отправьте этот файл преподавателю (через [ЦДО](online-edu.mirea.ru)).

**Способ Б: Сохранение на Google Диск**
1.  Нажмите **File** → **Save a copy in Drive**.
2.  Ноутбук сохранится в корень вашего Диска.
3.  Нажмите правой кнопкой на файл в Диске → **Поделиться (Share)** → Скопируйте ссылку с доступом "Читатель" или "Комментатор" и отправьте преподавателю.
